## Featured Projects

### 1. Heart Disease Prediction System

[**Repository →**](https://github.com/mars8-27/Heart-Disease-Prediction)

An educational machine-learning application that estimates a binary heart-disease outcome from 13 clinical features. It combines an XGBoost model with SHAP explanations, a Streamlit interface, and PostgreSQL persistence through SQLAlchemy.

**Technologies:** Python · Pandas · NumPy · XGBoost · scikit-learn · SHAP · Streamlit · PostgreSQL · SQLAlchemy · Docker · pytest

> Educational demonstration only. It is not a medical device or a clinically validated diagnostic tool.

### 2. Industrial Fire & Smoke Detection

[**Project and source code →**](https://github.com/mars8-27/smoke-and-fire-classification/tree/main/Smoke%20and%20fire%20detection%20using%20classical%20cv)

A video-based computer-vision prototype that combines HSV-based fire-region detection, motion and background-subtraction cues for smoke, and YOLOv8n object detection for scene context. Detection signals feed a risk-classification and monitoring interface.

**Technologies:** Python · OpenCV · NumPy · PyTorch · YOLOv8n

> A computer-vision prototype, not a certified fire-safety system. Quantitative detection performance has not yet been established.

### 3. Sign Gesture Recognition Prototype

[**Repository →**](https://github.com/mars8-27/signlanguagedetector)

A webcam-based, fixed-vocabulary gesture-classification prototype. MediaPipe Holistic extracts landmarks in the browser, FastAPI receives frames over WebSockets, and an ST-GCN model performs sequence classification with ONNX Runtime or PyTorch inference.

**Technologies:** Python · MediaPipe · FastAPI · WebSockets · PyTorch · ST-GCN · ONNX Runtime · Docker · pytest

> The current model uses procedurally generated training data and ten configured labels. It is not a general-purpose sign-language translator, and real-world recognition accuracy has not been established.
